# Atoll Path — работа на Мальдивах без агентства

Free bilingual (RU/EN) self-help guide for **direct-hire Maldives jobs**. Not an employment agency, not Immigration, not a visa issuer, no offer guarantee.

- 14-step path: resort offer → employer **work permit** in [Xpat](https://xpat.egov.mv/) → **Entry Pass** → ticket (only if the contract says so) → **Work e-Visa** within 15 days
- Official sources: [immigration.gov.mv](https://immigration.gov.mv/), Xpat, MyCareer, MIRA, LRA
- Vacancy decoder and offer inspector (stated / not stated / check)
- On-device CV and documents (localStorage — not a passport cloud)
- Trust scale A–D; vlog salaries are level C, not a contract

Live: [atoll-path.vercel.app](https://atoll-path.vercel.app)
